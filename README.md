# 🧮 Basic Calculator

A simple and responsive calculator built using **HTML, CSS, and JavaScript**. This project performs basic arithmetic operations with a clean user interface and is perfect for beginners learning front-end web development.

## 🚀 Live Demo

🔗 **Live Preview:** https://shivamproject.codeberg.page/calculator

## 📂 GitHub Repository

🔗 https://github.com/Developer-Shivam-Tiwary/basic-calculator

---

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧹 All Clear (AC)
- ⌫ Delete (Backspace)
- 📱 Responsive Design
- ⚡ Fast and Lightweight
- 🎨 Clean User Interface

## 💻 Run Locally

1. Clone the repository

```bash
git clone https://github.com/Developer-Shivam-Tiwary/basic-calculator.git
```

2. Navigate to the project folder

```bash
cd basic-calculator
```

3. Open `index.html` in your browser.

No installation or dependencies are required.
